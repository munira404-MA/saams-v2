# SAAMS v6.0 — إصلاح نهائي لتجاوب النظام على الجوال

تم في هذا الإصدار:

- جعل القائمة الجانبية مخفية بالكامل عند إغلاقها، فلا يبقى أي جزء أزرق يغطي الشاشة.
- فتح القائمة كـ Drawer فوق الصفحة من اليمين بالعربي ومن اليسار بالإنجليزي.
- منع القائمة من تصغير الصفحة أو دفع المحتوى جانبًا.
- إغلاق القائمة عند الضغط خارجها، اختيار شاشة، أو الضغط على Escape.
- منع تمرير الصفحة الخلفية أثناء فتح القائمة.
- جعل الشاشة الرئيسية والبطاقات والفلاتر بعرض الهاتف بالكامل.
- تحويل بطاقات الشاشة الرئيسية إلى عمود واحد على الهواتف الصغيرة.
- تحسين الشريط العلوي وأسماء المستخدم والأزرار للشاشات الضيقة.

بعد الرفع إلى GitHub وانتظار Vercel حتى Ready، يفضل فتح الموقع في Safari ثم تحديث الصفحة تحديثًا كاملًا.
