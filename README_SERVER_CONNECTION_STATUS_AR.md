# حالة الاتصال بالتشغيل الفعلي

تمت إضافة فحص آمن لحالة إعدادات الخادم داخل: الإعدادات > معلومات النظام.

المتغيرات المطلوبة على منصة الاستضافة:
- `VITE_SUPABASE_URL` (أو `SUPABASE_URL`)
- `VITE_SUPABASE_ANON_KEY` (أو `SUPABASE_ANON_KEY`)
- `SUPABASE_SERVICE_ROLE_KEY`

مهم: لا يوضع `SUPABASE_SERVICE_ROLE_KEY` داخل ملفات الواجهة أو داخل Git أو أي ملف يتم توزيعه للمستخدمين.
واجهة حالة النظام لا تعرض قيم المفاتيح، وإنما تعرض فقط هل هي موجودة أم لا.
