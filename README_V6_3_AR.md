# SAAMS v6.3 — الصلاحيات المخصصة وكلمات المرور

التعديلات:

- تحسين ألوان قائمة الإعدادات لتكون واضحة.
- عند إنشاء موظف إدارة، تختارين يدويًا الشاشات التي يستطيع فتحها:
  الرئيسية، الفواتير، الأصول، السلف، التقارير، المستخدمون، الإعدادات.
- لا توجد قوالب جاهزة؛ الاختيار يدوي بالكامل.
- القائمة الجانبية والمسارات داخل النظام تتغير حسب صلاحيات الموظف.
- حساب الحضانة يستطيع فتح الإعدادات لتغيير كلمة مروره فقط.
- مدير النظام يستطيع رؤية كلمة مرور أي مستخدم من شاشة المستخدمين عبر زر إظهار/إخفاء.
- كلمة المرور الجديدة تُحفظ في نسخة المعاينة المحلية.

ملاحظة مهمة:
هذه النسخة التجريبية تحفظ كلمات المرور في المتصفح لتسهيل المعاينة. في النسخة التشغيلية الفعلية يجب استخدام Supabase Auth، وعندها لا يُنصح بأن يستطيع أي مدير قراءة كلمة المرور الأصلية؛ الأفضل أن يستطيع إعادة تعيينها فقط.
