# تحسين قراءة ملفات PDF الكبيرة

تم تعديل OCR لمعالجة ملفات الفواتير الطويلة على دفعات داخلية من 8 صفحات بدل إرسال الملف كاملًا في طلب رؤية واحد.

- يحافظ على أرقام الصفحات الأصلية بعد دمج النتائج.
- يقرأ كل صفحة في الملف الكبير ولا يسمح بسقوط الصفحات المتأخرة بصمت.
- يعتبر صفحات استكمال الفاتورة (مثل Page 2/2 أو صفحات الأصناف/الإجماليات) صفحات فاتورة ويربطها بالمتسلسل نفسه.
- بعد دمج الدفعات، يعاد ربط إيصالات الخصم قبل/بعد الفاتورة على مستوى الملف كاملًا.
- الفواتير متعددة الصفحات يمكن أن تمتد عبر حد دفعتين وتظل تُجمع بالمتسلسل.
