# SAAMS v5.0 — وحدة الأصول

تم تنفيذ شاشة الأصول حسب الصلاحيات:

- الإدارة: عرض سجل الأصول وإضافة أصل جديد فقط.
- الحضانات: لا يظهر لها زر إضافة أصل. تظهر لها طلبات النقل والفائض والإسقاط.
- طلب النقل: من، إلى، اسم الأصل، رقم الباركود، سبب النقل.
- طلب الفائض: من، اسم الأصل، رقم الباركود، سبب الفائض، بدون حقل «إلى».
- طلب الإسقاط: من، اسم الأصل، رقم الباركود، سبب الإسقاط.
- تصوير أو رفع صورة الباركود: النظام يحاول قراءة الباركود تلقائيًا عبر BarcodeDetector ثم يعبئ بيانات الأصل إذا كان موجودًا في السجل.
- إذا لم يدعم المتصفح القراءة المباشرة، يمكن إدخال رقم الباركود يدويًا.
- لا توجد طباعة باركود أو ملصقات، حسب الطلب.

## تجربة الصلاحيات
في نسخة المعاينة الحالية:
- أي اسم مستخدم عادي يعرض صلاحية الإدارة.
- إذا احتوى اسم المستخدم على `nursery` أو كلمة `حضانة` تظهر واجهة الحضانة.
