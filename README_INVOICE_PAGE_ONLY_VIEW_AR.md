# تحديث عرض الفاتورة فقط

- زر عرض الفاتورة بعد الحفظ يفصل صفحات الفاتورة المحددة من ملف PDF الأصلي ويعرضها وحدها.
- الفاتورة متعددة الصفحات تعرض جميع صفحاتها المرتبطة فقط.
- إيصالات الخصم ورسائل البنك لا تدخل ضمن عرض الفاتورة نفسها.
- تمت إضافة إصلاح لربط صفحات الفاتورة المتعددة باستخدام رقم المتسلسل على مستوى الصفحة حتى لا تظهر الصفحة الثانية كسطر ضعيف منفصل.
- كل صفحة في الملف تبقى ظاهرة في تصنيف المراجعة، حتى لو تعذرت قراءتها آليًا.
