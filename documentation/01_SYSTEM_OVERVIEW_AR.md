# SAAMS Official v1.0

منظومة الأصول والسلف الذكية هي منصة موحدة لإدارة:

- الفواتير وقراءتها بالذكاء الاصطناعي.
- الأصول وطلبات النقل والفائض والإسقاط.
- السلف الشهرية وسلف الفعاليات.
- التقارير والمرفقات.
- المستخدمين والصلاحيات.
- سجل العمليات والتنبيهات والتحليلات.

## البيئة الفنية

- React + Vite
- Vercel
- Supabase Database
- Supabase Auth
- Supabase Storage
- OpenAI Vision API
