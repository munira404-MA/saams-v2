# دليل الحضانة

1. تسجيل الدخول باسم المستخدم وكلمة المرور.
2. رفع أو تصوير الفاتورة.
3. مراجعة البيانات المقروءة وإرفاق إيصال البطاقة عند الحاجة.
4. حفظ الفاتورة وإرسالها للمراجعة.
5. متابعة المصروف والمتبقي من السلفة.
6. تقديم طلب نقل أو فائض أو إسقاط للأصل.
7. متابعة حالة الطلبات والفواتير.
8. تغيير كلمة المرور من الإعدادات.
