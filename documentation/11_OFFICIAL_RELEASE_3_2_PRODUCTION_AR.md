# SAAMS Enterprise Official Release 3.2

## النسخة الرسمية الأولى

- تنظيف القائمة وحذف الشاشات المكررة.
- ترتيب القائمة: الرئيسية، الإدارة، مركز القيادة التنفيذي، النظام، المساعدة.
- تحويل «ما الجديد» إلى مركز مساعدة متكامل.
- إضافة رفع الفواتير بالسحب والإفلات.
- دعم التصوير والمعاينة والـ OCR والمرفقات.
- Timeline للفواتير والأصول.
- شريط المخصص والمصروف والمتبقي في السلف.
- تصدير التقارير إلى Excel وحفظها PDF.
- إضافة معلومات آخر نشاط للمستخدمين.
- النسخ الاحتياطي وسجل العمليات ومعلومات الإصدار ضمن الإعدادات.
- تحسين الانتقالات والبطاقات والألوان والجوال.
