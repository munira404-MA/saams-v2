# SAAMS v3.2.2 — الصلاحيات اليدوية المرتبة

- لم يتم تغيير طريقة الصلاحيات.
- مدير النظام ما زال يحدد صلاحية كل شاشة يدويًا.
- تم ترتيب الصلاحيات ضمن مجموعات:
  - الرئيسية.
  - الإدارة.
  - الإدارة التنفيذية.
  - النظام.
- الشاشة الرئيسية تبقى مفعلة دائمًا لموظف الإدارة.
- يظهر عدد الصلاحيات المفعلة داخل كل مجموعة.
