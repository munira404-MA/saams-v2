# SAAMS v5.5 — صلاحيات الحضانات

- حساب الحضانة يرى فقط: الرئيسية، الفواتير، الأصول، السلف، التقارير.
- لا تظهر له إدارة المستخدمين أو الإعدادات أو وظائف الإدارة.
- جميع بيانات الشاشات مفلترة تلقائيًا على الحضانة المرتبطة بالحساب.
- لا يستطيع حساب الحضانة اعتماد أو إرجاع الفواتير، إضافة أصل، إنشاء سلفة، أو اعتماد/رفض طلبات الأصول.
- شاشة التقارير والتصدير تخص الحضانة المسجلة فقط.
