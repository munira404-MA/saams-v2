# SAAMS v2 Complete Starter

هذه النسخة تحتوي فعليًا على مجلد `src` وكل ملفات البداية.

## رفعها إلى GitHub

ارفعي محتويات هذا المجلد إلى مستودع `saams-v2`، ومن ضمنها مجلد `src` كاملًا.

لا ترفعين ملف `.env` إن أنشأته. ارفعي فقط `.env.example`.

## النشر

بعد رفع الملفات، نربط المستودع بـ Vercel ونضيف متغيرات البيئة هناك.
