# SAAMS v4.1 — فصل الفواتير والإيصالات داخل PDF متعدد الصفحات

هذه النسخة مخصصة للملفات التي تحتوي عدة فواتير وإيصالات بطاقة داخل PDF واحد.

## ما تمت إضافته
- تصنيف كل صفحة إلى: فاتورة، إيصال بطاقة، أو صفحة أخرى.
- إنشاء سجل مستقل لكل فاتورة حسب ترتيب الصفحات.
- ربط إيصال البطاقة بالفاتورة المناسبة اعتمادًا على الصفحة القريبة، التاريخ، المبلغ، المورد، وأرقام التسلسل المكتوبة.
- عدم رفض الملف لمجرد أن الإيصال موجود في صفحة منفصلة داخل نفس PDF.
- عرض قائمة بالفواتير المكتشفة داخل الملف قبل الحفظ.
- عرض أرقام صفحات الفاتورة والإيصال المرتبط.
- حفظ كل فاتورة كسجل مستقل مع الاحتفاظ بمرجع صفحة الفاتورة وصفحات الإيصال.

## مثال الملف 30001.pdf
النظام يجب أن يميز مثلًا:
- الصفحة 1 إيصال بطاقة مرتبط بفاتورة الصفحة 2.
- الصفحة 4 إيصال بطاقة مرتبط بفاتورة الصفحة 5.
- الصفحة 6 إيصال بطاقة مرتبط بفاتورة الصفحة 7.
- الصفحة 11 إيصال بطاقة مرتبط بفاتورة الصفحة 12.
- بقية صفحات الفواتير النقدية تحفظ بدون إيصال بطاقة.
