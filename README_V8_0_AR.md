# SAAMS v8.0 — النسخة التنفيذية والذكية

المضاف في هذه النسخة:

- لوحة مدير عام تنفيذية بمؤشرات ورسوم وملخص للعمليات.
- سجل الأصل لحركات النقل والفائض والإسقاط فقط، بدون الشراء.
- سجل كامل داخل تفاصيل الفاتورة.
- جرس إشعارات فعلي مبني على سجل العمليات.
- مركز مرفقات للفواتير الأصلية وإيصالات البطاقة مع العرض والتنزيل وZIP.
- مساعد ذكي داخل النظام للبحث السريع والتنقل بين الشاشات.
- صلاحيات اختيارية للشاشات الجديدة لموظفي الإدارة.
- استمرار جميع خصائص الموبايل والصلاحيات السابقة.

ملاحظات:

- النسخة الحالية للمعاينة، وتعتمد على Local Storage للبيانات وسجل العمليات.
- مركز المرفقات يبدأ بالامتلاء بعد رفع وحفظ فواتير جديدة في هذه النسخة.
- المساعد الذكي الحالي يجيب من بيانات المعاينة المحلية؛ عند ربط Supabase سيقرأ البيانات الحقيقية.
