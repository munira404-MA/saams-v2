# SAAMS v7.0 — سجل العمليات المؤسسي

تمت إضافة سجل تدقيق مركزي يسجل العمليات تلقائيًا في نسخة المعاينة، ومنها:

- تسجيل الدخول.
- رفع الفواتير.
- اعتماد الفواتير.
- إرجاع الفواتير مع السبب.
- إضافة أصل.
- طلب نقل / فائض / إسقاط.
- اعتماد ورفض طلبات الأصول.
- إنشاء وإغلاق وإعادة فتح السلف.
- إضافة وتعديل وتفعيل وحذف المستخدمين.
- تحديث الإعدادات وتنزيل النسخ الاحتياطية.

شاشة سجل العمليات تشمل:

- فلاتر التاريخ والمستخدم والحضانة والشاشة ونوع العملية.
- البحث برقم الفاتورة أو الباركود أو اسم الحضانة.
- ألوان مختلفة حسب نوع العملية.
- نافذة تفاصيل لكل عملية.
- عرض الحالة قبل وبعد الحركة عند توفرها.
- تصدير سجل العمليات إلى Excel.
- تصميم متجاوب للموبايل والآيباد والكمبيوتر.

مهم:
السجل حاليًا محفوظ في Local Storage للمعاينة. عند الربط النهائي بـ Supabase سينتقل إلى جدول audit_logs محمي، ولا يسمح للمستخدمين بتعديله أو حذفه.
