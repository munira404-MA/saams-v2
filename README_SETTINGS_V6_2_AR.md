# SAAMS v6.2 — مركز الإعدادات

تمت إضافة شاشة إعدادات كاملة بنفس هوية النظام، وتشمل:

- الحساب الشخصي.
- ملخص إدارة المستخدمين.
- إضافة الحضانات وتعديلها وتفعيلها أو إيقافها.
- إعدادات الفواتير والذكاء الاصطناعي.
- إعدادات أنواع السلف.
- إعدادات التنبيهات.
- تنزيل واسترجاع نسخة احتياطية JSON لإعدادات المعاينة.
- سجل العمليات.
- معلومات النظام وحالة الخدمات.
- تصميم متجاوب للموبايل والآيباد والكمبيوتر.

## ملاحظات أمان

مفتاح OpenAI لا يظهر داخل شاشة الإعدادات ولا يُحفظ في المتصفح.
يظل محفوظًا بأمان داخل Vercel باسم:

OPENAI_API_KEY
