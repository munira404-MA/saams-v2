# إصلاح حفظ فواتير حسابات الحضانات

- يتم جلب UID والجلسة الحالية من Supabase وقت الحفظ.
- حساب الحضانة يأخذ nursery_id من public.profiles مباشرة ولا يعتمد على اختيار الواجهة.
- التحقق من أن السلفة المختارة تخص نفس الحضانة وأنها مفتوحة.
- إذا توجد سلفة مفتوحة واحدة فقط يتم ربطها تلقائياً.
- إذا لا توجد سلفة مفتوحة تظهر رسالة واضحة ولا يتم إنشاء فاتورة غير مرتبطة.
- إذا توجد أكثر من سلفة مفتوحة يطلب النظام اختيار السلفة المطلوبة.
- تحسين رسائل أخطاء RLS وربط الحضانة.
