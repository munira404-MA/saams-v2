# SAAMS v5.2 — شاشة السلف

تمت إضافة شاشة متكاملة للسلف الشهرية وسلف الفعاليات.

## ما تمت إضافته

- الإدارة فقط تستطيع إدراج سلفة جديدة.
- اسم السلفة يُكتب يدويًا، لذلك يمكن دمج أكثر من شهر في سلفة واحدة مثل: **سلفة أغسطس وسبتمبر 2026**.
- اختيار نوع السلفة: شهرية أو فعالية.
- تحديد فترة السلفة من تاريخ إلى تاريخ.
- اختيار الحضانات المشمولة وتحديد مبلغ مستقل لكل حضانة.
- خيار تطبيق مبلغ موحد على الحضانات المحددة.
- حفظ السلفة كمسودة أو فتحها مباشرة لرفع الفواتير.
- إغلاق وإعادة فتح نافذة رفع الفواتير.
- عرض المبلغ المخصص، المصروف، المتبقي، عدد الفواتير، ونسبة الاستخدام.
- شاشة خاصة بالحضانة تعرض رصيدها فقط.
- كل فاتورة معتمدة مرتبطة بالسلفة تخصم قيمتها تلقائيًا من رصيد الحضانة.
- شاشة تفاصيل تعرض الفواتير المرتبطة بكل حضانة.
- زر **معاينة شاشة الحضانة** متاح للإدارة لتجربة الصلاحيات.

## الملفات المعدلة

- `src/styles.css`

## ملاحظة

هذه النسخة تعمل ببيانات معاينة داخل الواجهة. الربط الدائم مع Supabase وربط الفواتير المعتمدة فعليًا بالسلفة سيكون في مرحلة قاعدة البيانات.
