# SAAMS v5.1 — اعتماد ورفض طلبات الأصول

تمت إضافة:
- زر اعتماد للطلبات قيد الاعتماد.
- زر رفض يفتح نافذة إلزامية لسبب الرفض.
- ظهور سبب الرفض داخل تفاصيل الطلب وفي الجدول.
- نافذة عرض تفاصيل طلب النقل أو الفائض أو الإسقاط.
- زر «معاينة طلبات الحضانة» للإدارة لفتح نماذج النقل والفائض والإسقاط وتجربتها.
- طلب النقل يظهر: من، إلى، الأصل، الباركود، والسبب.
- طلبا الفائض والإسقاط لا يظهر فيهما حقل «إلى».
