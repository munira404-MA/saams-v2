# SAAMS v8.1 — الذكاء التحليلي والتوصيات

تمت إضافة طبقة ذكاء تحليلية داخل النظام تشمل:

- توصيات تلقائية في لوحة المدير العام.
- اكتشاف الفواتير المحتمل تكرارها حسب المورد والمبلغ والتاريخ ورقم الفاتورة.
- تنبيه عند وجود فواتير معلقة منذ فترة طويلة.
- تنبيه عند قرب انتهاء رصيد السلفة.
- تحليل أكثر أسباب رفض أو إرجاع الفواتير تكرارًا.
- تنبيه للأصول كثيرة النقل.
- تنبيه لطلبات النقل والفائض والإسقاط غير المحسومة.
- ملخص ذكي داخل شاشة التقارير.
- تطوير المساعد الذكي ليجيب من بيانات النظام المحلية عن:
  - المتبقي من السلف.
  - الفواتير المرفوضة أو المعادة.
  - طلبات النقل المعلقة.
  - طلبات الفائض والإسقاط.
  - الفواتير المحتمل تكرارها.
  - توصيات النظام.

مهم:
هذه النسخة تعتمد على بيانات المعاينة المخزنة محليًا. بعد ربط Supabase ستعمل نفس التحليلات على البيانات الحقيقية.
