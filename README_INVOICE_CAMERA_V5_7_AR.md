# SAAMS v5.7 — رفع أو تصوير الفاتورة

- رفع PDF أو صور من الجهاز.
- تصوير الفاتورة مباشرة بالكاميرا الخلفية للهاتف أو الآيباد.
- بدء OCR تلقائيًا بعد التقاط الصورة.
- تصوير صفحة إضافية وإضافتها لقائمة المرفقات.
- رفع أو تصوير إيصال البطاقة عند اختيار الدفع بالبطاقة.
- لا يتضمن مسح QR أو باركود الفاتورة.
