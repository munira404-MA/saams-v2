# استرداد حساب مدير النظام

تمت إضافة أداة استرداد آمنة إلى صفحة تسجيل الدخول.

## الإعداد المطلوب في Vercel
أضف متغير بيئة جديدًا باسم:

SAAMS_ADMIN_RECOVERY_CODE

واجعل قيمته رمزًا سريًا قويًا لا يقل عن 12 حرفًا/رقمًا، وفعّله في Production وPreview، ثم نفّذ Redeploy.

## الاستخدام
1. افتح صفحة تسجيل الدخول.
2. اختر «إعادة تعيين كلمة مرور مدير النظام».
3. أدخل اسم المستخدم (مثل munira).
4. أدخل كلمة مرور جديدة (8 أحرف على الأقل) وأكدها.
5. أدخل رمز الاسترداد الموجود في Vercel.
6. اضغط «تغيير كلمة المرور».

الخادم يتحقق أن اسم المستخدم موجود في public.profiles وأن دوره super_admin وأن الحساب غير موقوف، ثم يغير كلمة مرور مستخدم Supabase Authentication المرتبط بنفس UUID.

لا يتم إرسال service role key إلى المتصفح ولا يتم حفظ رمز الاسترداد في localStorage/sessionStorage.

## تحديث مفاتيح Supabase الجديدة
- يستخدم الخادم `SUPABASE_SECRET_KEY` أولاً للعمليات الإدارية.
- عند رفض المفتاح الجديد بسبب توافق خدمة Auth، يجرب `SUPABASE_SERVICE_ROLE_KEY` تلقائياً كخيار احتياطي.
- يستخدم النظام `SUPABASE_PUBLISHABLE_KEY` أولاً للجلسات العامة، ثم مفاتيح anon القديمة عند الحاجة.
- لا يتم إرسال أو عرض أي مفتاح سري في المتصفح.
