# حسابات التشغيل الفعلي – SAAMS Enterprise 3.2.2

تم تحديث شاشة المستخدمين لتجهيز الحسابات الفعلية للتشغيل:

- زر سريع لإنشاء حساب حضانة.
- ربط كل حساب حضانة بحضانة واحدة فقط.
- منع إنشاء أكثر من حساب رئيسي لنفس الحضانة من شاشة الإدارة.
- اقتراح اسم مستخدم تلقائي للحضانة.
- توضيح نطاق البيانات المقفل للحضانة.
- عرض عدد الحضانات المرتبطة بحساب وعدد الحضانات التي ما زالت بدون حساب.
- عند تفعيل Supabase: إنشاء/تعديل/إيقاف/حذف الحسابات من قاعدة البيانات الفعلية عبر API إداري آمن.
- عدم عرض كلمات المرور في قائمة المستخدمين.
- حساب موظف الإدارة يبقى بصلاحيات يحددها مدير النظام يدويًا.

## ملاحظة تشغيلية
يتطلب إنشاء الحسابات الفعلية وجود متغير `SUPABASE_SERVICE_ROLE_KEY` في بيئة الخادم فقط، ولا يتم وضعه في الواجهة الأمامية.
